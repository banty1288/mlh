# 75-second demo walkthrough

**Before recording:** open the app, use a real public wallet address with visible activity, verify that the public RPC responds, and keep a valid Gemini API key ready if you plan to show the AI feature. Never show the key in the recording.

1. **0–10 seconds — Problem:** “Solana transactions are public, but raw signatures and program IDs are difficult to interpret. Solana Sentinel turns that activity into a readable explanation.”
2. **10–25 seconds — Solana integration:** paste a real public wallet address with activity and analyze it. Show the native SOL balance, token inventory and recent signatures. Explain that the app queries Solana mainnet directly using JSON-RPC.
3. **25–42 seconds — Evidence:** open the activity table and a transaction detail. Point out the status, fee, wallet net SOL delta, parsed instructions/program IDs and token balance changes. Open one signature in Solana Explorer.
4. **42–62 seconds — AI:** enter the Gemini key off-camera or before recording, then generate a briefing. Show that the model separates observed facts from interpretation and calls out data limitations.
5. **62–75 seconds — Trust and close:** show the review signals and export button. “Sentinel is read-only: no private keys, no signing and no transaction broadcast. AI explains the evidence; the chain remains the source of truth.”

Do not record with a demo/system address if it has no wallet activity. Do not claim fraud detection, a security audit, USD valuation or complete wallet history.
